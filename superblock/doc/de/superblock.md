## Superblock

Mit der Superblock-App können Sie andere Kanäle dauerhaft aus Ihrem Netzwerk-Stream, Ihren Benachrichtigungen, privaten Nachrichten und Erwähnungen blockieren. Sobald ein Kanal blockiert ist, sollte er für Sie praktisch unsichtbar sein.

### Kanäle aus Ihrem Netzwerk-Stream blockieren

Wenn Sie einen Beitrag oder Kommentar von jemandem sehen, von dem Sie in Ihren Streams nichts mehr sehen möchten, können Sie diese Person blockieren, indem Sie auf ihr Avatar-Bild klicken und „Vollständig blockieren” auswählen.

### Manuelles Hinzufügen von Kanälen zur Sperrliste

Sie können Kanäle manuell zur Sperrliste hinzufügen, indem Sie die Seite [baseurl]/superblock aufrufen, auf „Neuen Eintrag hinzufügen” klicken und dann die Kanaladresse in das angezeigte Textfeld eingeben.

Auf diese Weise können Sie Kanäle proaktiv sperren, noch bevor Sie Inhalte von ihnen in Ihren Streams sehen.

Beachten Sie, dass derzeit nur Kanäle, die Ihrem Hub bekannt sind, auf diese Weise gesperrt werden können.

### Einen Kanal entsperren

Um einen Kanal aus der Sperrliste zu entfernen, klicken Sie auf der Seite [baseurl]/superblock auf das Papierkorb-Symbol rechts neben dem Eintrag.

### Einen Kanal von der Website blockieren (nur für Administratoren)

Ein Website-Administrator kann einen Kanal zur websiteweiten Sperrliste hinzufügen, indem er auf das Avatar-Bild in einem Beitrag oder Kommentar des Kanals klickt, den er blockieren möchte, und „Von Website blockieren“ auswählt.

Diese Funktion steht nur Website-Administratoren zur Verfügung.
